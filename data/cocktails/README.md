The file contains 90 recipes scraped from the IBA website and is normalized at
runtime by `lib/cocktails/iba-adapter.ts`. The upstream MIT license is preserved
in `THIRD_PARTY_LICENSE_iba-cocktails.txt`.

The Bar Assistant `v5` schema, Margarita sample, base glass list, and base
method list were consulted as structural references only. No Bar Assistant data
or application code is bundled in this project.
